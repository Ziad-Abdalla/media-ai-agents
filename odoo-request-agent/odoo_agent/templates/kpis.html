Definitions: auto-resolved = vendor and production matched without a person. Approval rate = approved / (approved + rejected). Approved = the writes ran (a click stopped by the kill switch doesn't count). Success rate = draft POs not rolled back plus sent clarification replies, out of finished runs (rejections are a person's decision and are left out; a rollback can be a drill, so it is shown on its own). Handling time runs from the email's Date header to the draft PO in Odoo; "waiting for a person" is plan ready to the Approve click, which is queue time, not reading time. The same numbers: python -m odoo_agent kpis.
